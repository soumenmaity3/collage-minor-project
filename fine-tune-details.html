Complete Guide to Fine-Tuning in TensorFlow

1. What is Fine-Tuning?

Fine-tuning is a transfer learning technique where you take a pre-trained model (trained on a large dataset) and adapt it to your specific task by training it on your custom dataset. Instead of training from scratch, you leverage the knowledge already learned by the model.

Key Concept: Pre-trained models have already learned useful features from large datasets (like ImageNet with millions of images). Fine-tuning allows you to reuse these features for your specific problem.

2. Benefits of Fine-Tuning

  • Faster Training: Requires less time compared to training from scratch
  • Better Performance: Often achieves higher accuracy with less data
  • Less Data Required: Works well even with smaller datasets
  • Proven Features: Leverages features learned from millions of images

3. Fine-Tuning Process - Step by Step

Step 1: Load a Pre-trained Model

Start with a model trained on a large dataset (e.g., VGG16, ResNet, MobileNet trained on ImageNet)

Step 2: Remove the Top Layer

Remove the final classification layer since it's specific to the original task (e.g., 1000 ImageNet classes)

Step 3: Freeze Base Layers

Initially freeze the pre-trained layers to preserve learned features

Step 4: Add Custom Layers

Add new layers tailored to your specific classification task

Step 5: Train the New Layers

Train only the new layers while keeping base layers frozen

Step 6: Unfreeze and Fine-Tune

Optionally unfreeze some base layers and train with a very low learning rate

4. Code Example: Without Fine-Tuning

Training a CNN from scratch without using pre-trained weights:

🔧 Training from Scratch - No Pre-trained Weights Custom CNN 
# ========================================
# IMPORT LIBRARIES
# ========================================
import tensorflow as tf
from tensorflow import keras
from tensorflow.keras import layers
import numpy as np

# ========================================
# STEP 1: LOAD AND PREPARE DATA
# ========================================
# Load CIFAR-10 dataset (32x32 color images, 10 classes)
(x_train, y_train), (x_test, y_test) = keras.datasets.cifar10.load_data()

# Normalize pixel values to [0, 1] range
x_train = x_train.astype('float32') / 255.0
x_test = x_test.astype('float32') / 255.0

# Convert labels to one-hot encoding
y_train = keras.utils.to_categorical(y_train, 10)
y_test = keras.utils.to_categorical(y_test, 10)

print(f"Training data shape: {x_train.shape}")
print(f"Training labels shape: {y_train.shape}")

# ========================================
# STEP 2: BUILD MODEL FROM SCRATCH
# ========================================
model_no_ft = keras.Sequential([
    # 🔷 First Convolutional Block
    layers.Conv2D(32, (3, 3), activation='relu', 
                  input_shape=(32, 32, 3), padding='same'),
    layers.BatchNormalization(),
    layers.Conv2D(32, (3, 3), activation='relu', padding='same'),
    layers.BatchNormalization(),
    layers.MaxPooling2D((2, 2)),
    layers.Dropout(0.25),
    
    # 🔶 Second Convolutional Block
    layers.Conv2D(64, (3, 3), activation='relu', padding='same'),
    layers.BatchNormalization(),
    layers.Conv2D(64, (3, 3), activation='relu', padding='same'),
    layers.BatchNormalization(),
    layers.MaxPooling2D((2, 2)),
    layers.Dropout(0.25),
    
    # 🔸 Third Convolutional Block
    layers.Conv2D(128, (3, 3), activation='relu', padding='same'),
    layers.BatchNormalization(),
    layers.Conv2D(128, (3, 3), activation='relu', padding='same'),
    layers.BatchNormalization(),
    layers.MaxPooling2D((2, 2)),
    layers.Dropout(0.25),
    
    # 🎯 Classification Head
    layers.Flatten(),
    layers.Dense(256, activation='relu'),
    layers.BatchNormalization(),
    layers.Dropout(0.5),
    layers.Dense(10, activation='softmax')
])

# ========================================
# STEP 3: COMPILE THE MODEL
# ========================================
model_no_ft.compile(
    optimizer=keras.optimizers.Adam(learning_rate=0.001),
    loss='categorical_crossentropy',
    metrics=['accuracy']
)

# Display model architecture
model_no_ft.summary()

# ========================================
# STEP 4: TRAIN THE MODEL
# ========================================
print("\n═══ Training Model from Scratch ═══")
history_no_ft = model_no_ft.fit(
    x_train, y_train,
    batch_size=128,
    epochs=20,
    validation_split=0.2,
    verbose=1
)

# ========================================
# STEP 5: EVALUATE PERFORMANCE
# ========================================
test_loss, test_acc = model_no_ft.evaluate(x_test, y_test, verbose=0)
print(f"\n✅ Test Accuracy: {test_acc:.4f}")
print(f"📊 Test Loss: {test_loss:.4f}")

5. Code Example: With Fine-Tuning

Using a pre-trained model (MobileNetV2) and fine-tuning it for CIFAR-10:

🚀 Transfer Learning with Fine-Tuning MobileNetV2 + ImageNet 
# ========================================
# IMPORT LIBRARIES
# ========================================
import tensorflow as tf
from tensorflow import keras
from tensorflow.keras import layers
from tensorflow.keras.applications import MobileNetV2

# ========================================
# STEP 1: PREPARE DATA
# ========================================
# Load CIFAR-10 dataset
(x_train, y_train), (x_test, y_test) = keras.datasets.cifar10.load_data()

# Normalize pixel values
x_train = x_train.astype('float32') / 255.0
x_test = x_test.astype('float32') / 255.0

# Convert to categorical
y_train = keras.utils.to_categorical(y_train, 10)
y_test = keras.utils.to_categorical(y_test, 10)

# ========================================
# STEP 2: CREATE DATA AUGMENTATION
# ========================================
data_augmentation = keras.Sequential([
    layers.RandomFlip("horizontal"),
    layers.RandomRotation(0.1),
    layers.RandomZoom(0.1),
])

# ========================================
# STEP 3: LOAD PRE-TRAINED BASE MODEL
# ========================================
print("🔽 Loading MobileNetV2 with ImageNet weights...")

base_model = MobileNetV2(
    input_shape=(32, 32, 3),
    include_top=False,      # ❌ Remove classification layer
    weights='imagenet'       # ✅ Use pre-trained weights
)

# ========================================
# STEP 4: FREEZE BASE MODEL LAYERS
# ========================================
base_model.trainable = False  # 🔒 Freeze all layers

print(f"📊 Base model has {len(base_model.layers)} layers")
print(f"🔒 Base model trainable: {base_model.trainable}")

# ========================================
# STEP 5: BUILD COMPLETE MODEL
# ========================================
model_ft = keras.Sequential([
    # Data augmentation layer
    data_augmentation,
    
    # Preprocess for MobileNetV2 (scale to [-1, 1])
    layers.Rescaling(scale=1./127.5, offset=-1),
    
    # 🎯 Pre-trained base model (frozen)
    base_model,
    
    # 🔧 Custom classification head
    layers.GlobalAveragePooling2D(),
    layers.Dropout(0.3),
    layers.Dense(128, activation='relu'),
    layers.BatchNormalization(),
    layers.Dropout(0.5),
    layers.Dense(10, activation='softmax')
])

# ========================================
# STEP 6: COMPILE MODEL (PHASE 1)
# ========================================
model_ft.compile(
    optimizer=keras.optimizers.Adam(learning_rate=0.001),
    loss='categorical_crossentropy',
    metrics=['accuracy']
)

model_ft.summary()

# ========================================
# STEP 7: PHASE 1 - TRAIN TOP LAYERS ONLY
# ========================================
print("\n╔════════════════════════════════════╗")
print("║  PHASE 1: Train New Layers Only  ║")
print("╚════════════════════════════════════╝")

history_phase1 = model_ft.fit(
    x_train, y_train,
    batch_size=128,
    epochs=10,
    validation_split=0.2,
    verbose=1
)

# ========================================
# STEP 8: UNFREEZE BASE MODEL LAYERS
# ========================================
print("\n╔════════════════════════════════════╗")
print("║  PHASE 2: Fine-Tune Base Model   ║")
print("╚════════════════════════════════════╝")

# Unfreeze the base model
base_model.trainable = True  # 🔓 Unfreeze

# Freeze all layers except the last 20
for layer in base_model.layers[:-20]:
    layer.trainable = False

trainable_count = len([l for l in base_model.layers if l.trainable])
print(f"🔓 Trainable layers: {trainable_count}")

# ========================================
# STEP 9: RECOMPILE WITH LOWER LR
# ========================================
model_ft.compile(
    optimizer=keras.optimizers.Adam(learning_rate=0.0001),  # ⚡ 10x lower!
    loss='categorical_crossentropy',
    metrics=['accuracy']
)

# ========================================
# STEP 10: FINE-TUNE THE MODEL
# ========================================
history_phase2 = model_ft.fit(
    x_train, y_train,
    batch_size=128,
    epochs=10,
    validation_split=0.2,
    verbose=1
)

# ========================================
# STEP 11: FINAL EVALUATION
# ========================================
test_loss, test_acc = model_ft.evaluate(x_test, y_test, verbose=0)

print("\n╔════════════════════════════════════╗")
print("║       FINAL RESULTS 🎉            ║")
print("╚════════════════════════════════════╝")
print(f"✅ Test Accuracy: {test_acc:.4f}")
print(f"📊 Test Loss: {test_loss:.4f}")

# ========================================
# STEP 12: COMPARE RESULTS
# ========================================
print("\n═══════════════ COMPARISON ═══════════════")
print(f"❌ Without Fine-Tuning: Acc = {test_acc_no_ft:.4f}")
print(f"✅ With Fine-Tuning:    Acc = {test_acc:.4f}")
print(f"📈 Improvement: +{(test_acc - test_acc_no_ft):.4f}")

6. Key Differences Explained

Without Fine-Tuning

  • Random weight initialization
  • Trains all layers from scratch
  • Requires more training time
  • Needs more data for good performance
  • Higher learning rate (0.001)
  • Simple architecture

With Fine-Tuning

  • Pre-trained weight initialization
  • Initially freezes base layers
  • Faster convergence
  • Works well with smaller datasets
  • Lower learning rate (0.0001)
  • Two-phase training strategy

7. Fine-Tuning Best Practices

Important Tips:
  1. Use a lower learning rate: When fine-tuning, use 10-100x smaller learning rate to avoid destroying pre-trained weights
  2. Freeze layers strategically: Start with all layers frozen, then gradually unfreeze from top to bottom
  3. Train in phases: First train new layers, then fine-tune the entire model
  4. Monitor for overfitting: Fine-tuned models can overfit on small datasets
  5. Use data augmentation: Especially important with smaller datasets

8. Common Pre-trained Models in TensorFlow

  • VGG16/VGG19: Simple architecture, good for learning
  • ResNet50/ResNet101: Deeper networks with skip connections
  • MobileNetV2: Lightweight, fast, mobile-friendly
  • InceptionV3: Multi-scale feature extraction
  • EfficientNet: State-of-the-art efficiency and accuracy
  • DenseNet: Dense connections between layers

9. When to Use Fine-Tuning

Use Fine-Tuning When:
  • You have a small to medium-sized dataset (< 100k images)
  • Your task is similar to the pre-training task (e.g., image classification)
  • You want faster training and better performance
  • You have limited computational resources
Train From Scratch When:
  • You have a very large dataset (millions of samples)
  • Your domain is very different from ImageNet (e.g., medical images, satellite imagery)
  • You need a custom architecture for specific requirements

10. Summary

Fine-tuning is a powerful technique that allows you to leverage pre-trained models for your specific tasks. By starting with weights learned from millions of images, you can achieve better performance with less data and training time. The key is to freeze the base model initially, train your custom layers, and then optionally fine-tune some base layers with a very low learning rate.
